# Self Learning English

这是一个以真实输出为核心的个人英语训练仓库。

## 当前目标

提升以下能力：

- 听力理解：听懂会议和日常对话
- 英语复述：听完一段内容后能用英语复述大意
- 日常交流：能用简单完整的句子进行基本对话
- 工作沟通：站会汇报、Bug 描述、技术讨论、需求确认
- 技术表达：用英语描述技术方案和问题
- 主动调用：能主动想起并使用练过的词汇和句式，而不只是"看得懂"

面试材料当前不维护。如果未来需要，会根据当时最新的经历重新编写。

## 核心学习流程

```
输入（听材料）
→ 第一次输出（复述）
→ 发现问题（语法、表达、词汇）
→ 提炼表达（3～5 个）
→ 替换练习（用自己的场景造句）
→ 再次输出（修正后的复述）
→ 定期复盘（周/月）
```

## 记录原则

- 不收集完整教材，只记录训练中真实遇到的问题
- 不追求笔记数量，一次只训练少量表达（3～5 个）
- 只记录真实犯过的错误，不提前整理"可能的错"
- 允许删除过时内容，仓库保持精简
- 语法随用随查，不建完整语法体系
- 面试材料不在本仓库维护，需要时根据最新经历重新编写

## 背景

我从 2024 年 4 月开始系统学习英语，到 2025 年初暂停，累计投入约 900 小时，词汇量达到 7500 左右，口语/听力约 A2 水平。

2026 年 7 月恢复学习，词汇量从 7500 掉到 6000 左右。这次目标更明确：提升实际交流能力。学习计划从每天 3-4 小时调整为每天 20-30 分钟高效训练，重点从大量输入转向输出驱动。

学习方法参考：[《人人都能用英语》](https://github.com/xiaolai/everyone-can-use-english)、[二语习得理论](https://baike.baidu.com/item/%E4%BA%8C%E8%AF%AD%E4%B9%A0%E5%BE%97%E7%90%86%E8%AE%BA/7802838)。
