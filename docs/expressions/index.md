# 语言块

这里收集可以直接用于真实交流的高频语言块。当前学习顺序以会议、技术问题、
协作和面试为主，日常英语作为补充。

每个语言块包含简单说明和至少三个例句。看到 `...` 时，可以替换人物、时间、
地点或具体事情。工作交流部分还包含更多例句和完整对话，用来练习如何把
多个语言块连接起来。

语言块页面是查阅库，不是每日背诵清单。每次只选择 3～5 个表达，用自己的项目
替换关键词，然后完成一次 60～90 秒的脱稿输出。

## 分类

- [工作交流](./work-communication.md)：当前主线；远程会议、进度、Bug、需求、
  技术解释、异步协作、评审、发布、面试和 Demo
- [通用对话](./conversation.md)：寒暄、邀约、同意拒绝、接话、总结和结束
- [常用搭配](./collocations.md)：可以放进句中或句尾的动词搭配和时间短语
- [日常生活](./daily-communication.md)：点餐、购物、问路、预约和就医等补充场景

## 当前优先顺序

1. 工作交流中的“听不清、远程会议和争取时间”
2. 汇报进度、描述 Bug、澄清和确认需求
3. 解释代码、系统和数据流
4. 异步协作、时区、项目介绍、面试和 Demo
5. 根据真实训练中暴露的问题，再查通用对话和常用搭配

配套材料和手机收听方式见[听力材料](../practice/listening/index.md)。
