# 语言块

这里收集日常生活和工作交流中可以直接使用的高频语言块。

每个语言块包含简单说明和三个例句。看到 `...` 时，可以替换人物、时间、
地点或具体事情。每天选择一些内容多读几遍，熟悉它们的完整声音和用法即可。

## 分类

- [日常生活](./daily-communication.md)：日常活动、计划、点餐、购物、问路、预约和就医
- [工作交流](./work-communication.md)：进度、Bug、会议、分工、评审、发布和线上故障
- [通用对话](./conversation.md)：寒暄、邀约、同意拒绝、接话、总结和结束
- [常用搭配](./collocations.md)：可以放进句中或句尾的动词搭配和时间短语
