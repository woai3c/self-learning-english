# 工作场景练习

## 说明

用于记录真实或模拟的工作英语输出练习。先从[工作交流语言块](../../expressions/work-communication.md)选择 3～5 个表达，再把人物、项目、技术栈和问题替换成自己的真实情况。

## 场景类型

- **远程会议自救**：没听清、请求重复、确认关键词、共享屏幕和网络问题
- **每日站会**：昨天完成了什么、今天计划做什么、有什么阻塞
- **异步汇报与交接**：跨时区更新进展、留下上下文、明确下一步负责人
- **Bug 描述与排查**：预期、实际结果、复现步骤、影响范围和原因猜测
- **需求确认**：用户目标、范围、验收标准、边界情况和截止时间
- **技术解释**：组件职责、请求链路、数据来源、技术选择和 trade-off
- **代码评审**：请求评审、解释修改、回应意见、确认是否可以合并
- **发布与事故**：部署状态、回滚、临时方案、监控和后续行动
- **项目介绍与 Demo**：项目目标、个人职责、挑战、行动、结果和功能演示
- **个人介绍与问答**：自我介绍、技术栈、项目经历、合作方式和工作安排

## 练习方式

1. 选一个真实场景和 3～5 个目标语言块
2. 只写关键词，不写完整逐字稿
3. 脱稿说 60～90 秒
4. 回听检查：
   - 卡顿是否超过 3 处？
   - 是否说了完整句子？
   - 是否有中式表达痕迹？
   - 关键词发音有没有问题？
   - 是否主动使用了目标语言块？
   - 对方是否能明确知道下一步行动？
5. 让 AI 扮演同事、PM、客户或其他沟通对象，继续追问两个问题
6. 纠正后再完整说一遍
7. 第二天不看文本重新回答同一场景

## 每周轮换

- 周一：会议自救
- 周二：Stand-up / 异步汇报
- 周三：Bug 描述与排查
- 周四：需求确认
- 周五：技术解释 / 代码评审
- 周六：项目介绍 / 技术问答 / Demo
- 周日：重新回答本周最卡的一次，或休息
