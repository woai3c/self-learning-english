# 工作场景练习

## 说明

用于记录真实或模拟的工作英语输出练习。

## 场景类型

- **每日站会 (Daily Stand-up)**：汇报昨天做了什么、今天计划做什么、有没有阻塞
- **Bug 描述**：What I expected / What actually happened / Steps to reproduce / My guess at the cause
- **技术方案解释**：向同事或 PM 解释技术选型、架构设计
- **需求确认**：和 PM 确认需求细节，提出疑问
- **表达不同意见**：在技术讨论中表达不同看法
- **请求澄清**：听不明白时请对方再说一遍或换个方式解释

## 练习方式

1. 选一个场景
2. 写下要表达的内容
3. 脱稿说出来，录音
4. 回听检查：
   - 卡顿是否超过 3 处？
   - 是否说了完整句子？
   - 是否有中式表达痕迹？
   - 关键词发音有没有问题？
5. 纠正后再录一遍
6. 同一段内容至少说 3 遍
