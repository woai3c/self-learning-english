# 走遍美国 (Family Album, U.S.A.) 练习记录

## 说明

这个目录用于记录《走遍美国》的小节训练。

每次练习以一个 Act（小节）为单位，不保存完整台词，只记录训练过程和发现的问题。

## 文件命名

```
episode-{集数}-act-{节数}.md
```

例如：`episode-02-act-01.md` 表示第 2 集第 1 节的练习记录。
