# 训练

当前训练围绕实际工作交流展开。每次先听一段短材料，再把其中 3～5 个表达放进
自己的工作场景中输出。

## 当前入口

- [听力材料](./listening/index.md)：B1 听力主线、A2 口语材料、真实程序员播客、
  手机收听方法和四周起步顺序
- [工作场景](./work-scenarios/index.md)：会议、站会、Bug、需求、
  技术解释、异步协作、面试和 Demo
- [工作交流语言块](../expressions/work-communication.md)：可直接用于练习的表达、
  例句和完整场景对话
- [每日回顾](./daily-retelling/index.md)：用英语复述当天做过的事情

## 历史练习

- [《走遍美国》](./family-album-usa/index.md)：已经完成的精听和脱稿复述记录。

## 每次训练的最低要求

1. 选择 1～3 分钟、带英文文本或字幕的工作材料。
2. 不看文本听两遍，判断人物目的、问题、决定和下一步行动。
3. 提炼 3～5 个能够迁移到自己工作的表达。
4. 用自己的项目完成一次 60～90 秒脱稿输出。
5. 回听、纠正，再完整说一遍。
