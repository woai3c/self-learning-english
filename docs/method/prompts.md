# 训练用 Prompt

保留在实际训练中会重复使用的 Prompt。

## 检查英语复述

```
我刚才用英语复述了一段内容，请帮我检查：
1. 语法错误（尤其是时态）
2. 不自然的中式英语表达
3. 可以改进的表达方式

以下是我的复述：
[粘贴复述内容]

请逐句分析，指出问题并给出修正版本。
```

## 分析口语错误

```
以下是我的英语口语录音转写内容。请注意：部分内容可能是语音识别错误，不是我的真实语法错误。

请帮我：
1. 区分语音识别错误和真实语法错误
2. 列出真实的语法和表达问题
3. 给出修正后的版本

转写内容：
[粘贴转写内容]
```

## 提取主动表达

```
以下是一段英语材料。请帮我从中提取 3～5 个适合口语练习的表达。

要求：
- 日常对话或工作中会用到
- 适合替换练习（可以换词造新句）
- 不要太简单的单词，重点是短语和句式

材料：
[粘贴材料内容]

对每个表达，请给出：含义、原句、两个替换例句。
```

## 生成替换练习

```
请帮我对以下表达进行替换练习：

表达：[填写表达]
含义：[填写含义]

请用这个表达造 5 个不同场景的句子，包括：
- 日常生活场景
- 工作场景
- 技术讨论场景
```

## 检查工作场景表达

```
当我使用英语向你提问时：
1. 先判断我的表达是否有语法错误，如果有，指出错误并说明正确表达
2. 然后用英语回答我的问题
3. 如果没有语法错误，直接用英语回答
```
