# 每日训练流程

## 当前阶段的材料

- B1 美式工作听力主线：[VOA Let's Learn English Level 2](https://learningenglish.voanews.com/p/6765.html) 的 Lesson 1～3，以及 `Better Conversations at Work`；无需注册，听力材料页提供官方 YouTube、课程文本和直接 MP3
- A2 口语转化：使用 VOA Level 1 的 Lesson 8、41 和 47 做美式跟读，再使用[925 English](https://www.businessenglishpod.com/category/925-english/) 和工作交流语言块补充表达、替换和角色扮演；925 English 不默认作为美式发音范本
- 清晰工作讲解：[Speak Confident English](https://www.speakconfidentenglish.com/podcast/) 的会议、澄清、反馈和项目汇报内容
- 技术听力：VOA Technology Report 和发音清楚、有英文字幕的美式技术讲解
- 真实材料：优先选择美式说话人的 Developer Tea、Stack Overflow Podcast 等片段；平台内说话人口音可能变化，训练前先试听
- 多口音接触：British Council 和 BBC 当前只占少量泛听，达到 B2 后再系统增加
- 注册课程：USA Learns 必须创建免费账户并登录，只作可选补充，不影响当前主线
- 输出：线上会议、站会、Bug、需求、技术解释、异步协作、项目介绍和功能演示

精听材料以美式发音和工作交流为主。完整课程中与工作无关的家庭、旅游和社区主题不进入当前主线；完整材料清单、使用顺序和手机收听方法见[听力材料](../practice/listening/index.md)。

《走遍美国》的历史练习记录继续保留，但不再作为当前主线。每天优先完成一段 B1 工作听力，再用 A2 难度的简单句完成脱稿输出。听力 B1 和口语 A2 分开判断，不要求复述使用和原材料一样复杂的句子。

## 核心流程

```
听材料
→ 理解内容
→ 第一次复述
→ 检查错误
→ 提炼 3～5 个表达
→ 替换造句
→ 第二次复述
→ 隔天复习
```

## 最低版：20～30 分钟

### 第一阶段：听和理解（5～8 分钟）

1. 选择一段 B1 工作材料；分级材料可以听完整一段，真实材料截取 1～3 分钟
2. 先不看文本，听 1～2 遍，抓大意
3. 遇到听不懂的地方，看文本确认
4. 确保没有不认识的关键词

### 第二阶段：第一次复述（5 分钟）

1. 关掉材料，用自己的话复述刚才听到的内容
2. 可以录音，方便回听
3. 不追求完美，先说出来

### 第三阶段：检查和提炼（5～8 分钟）

1. 回听录音或回忆复述过程，找出问题：
   - 哪里卡住了？
   - 哪里用了中文思维？
   - 哪里时态搞错了？
   - 哪个词不确定？
2. 从材料中提炼 3～5 个值得练习的表达
3. 每个表达用自己的场景造 2～3 个替换句

### 第四阶段：第二次复述（5 分钟）

1. 重新复述同一段内容
2. 尝试主动使用刚刚提炼的表达
3. 对比两次复述的差异

### 隔天复习

- 第二天花 3～5 分钟重新复述同一段内容
- 检查重点表达是否还能主动使用
- 一周后再复述一次，确认掌握程度

## 完整版：60～90 分钟

先完成 20～30 分钟最低版，再从下面的模块中按需选择，直到当天总时长达到 60～90 分钟；不要求把所有模块全部完成。

- 跟读 10～15 分钟：模仿当前材料的重音、停顿和连读
- 分级美式短听力 10～15 分钟：从 VOA Level 2 选一段，结束后用 3～5 句英语复述
- 技术短听力 10～15 分钟：从 VOA 或带英文字幕的技术视频截取 1～3 分钟
- 工作场景（A2 口语输出）15～20 分钟：把材料换成自己的项目，脱稿表达，检查后再说一遍
- 复听、再输出或词汇维护 5～10 分钟（可选）：重听最难的一段、重说最卡的部分，或复习当天遇到的词

完整版不是每天必须完成的硬指标。忙时只做最低版，避免因为时间不足而完全中断。

## 工作场景轮换

完整版中的 A2 口语模块按下面的场景轮换，不再作为训练计划之外的额外任务：

- 周一：远程会议自救 / 听不清时确认
- 周二：Stand-up / 异步进度汇报
- 周三：描述 Bug / 排查技术问题
- 周四：确认需求 / 讨论验收标准
- 周五：解释代码、架构或数据流
- 周六：项目介绍 / 技术问答 / Demo
- 周日：复述本周最难的一段，或休息

每个场景的训练方式：写下内容 → 脱稿说出来 → 录音 → 回听纠正 → 再录一遍。

## 材料比例和切换计划

- 当前听力 B1：50% 分级美式英语、30% 清晰的美式技术讲解、15% 美式自然材料、5% 英式或其他口音
- 达到 B2 后：70% 美式材料、30% 英式或其他口音；口语模仿仍保持美式发音
- A2 难度的句式主要用于替换和口语自动化，不再承担听力挑战；只有美式说话人的音频才用于跟读

精听材料必须带文本或字幕，内容以实际工作为主；通用英语只有能直接迁移到会议、协作、技术说明或工作寒暄时才作为补充。连续语言要占主要部分；跟读和口语模仿统一使用美式发音。当前接触英式或其他口音时只训练理解，不模仿发音。影视、技术新闻和真实播客可以补充语感，但不能代替工作对话。是否换阶段由实际训练表现决定，不机械地按日期切换。

## 听力和口语的级别标准

当前听力约为 B1，口语约为 A2。听力使用 B1 新材料训练；口语继续使用简单句，重点解决卡顿、组织顺序和回答追问，不提前追求复杂句。

听懂率按主要信息估算，不按听出的单词数量计算：能否说出主题、人物目的、关键事实和最后结果。

- [VOA Let's Learn English Level 2](https://learningenglish.voanews.com/p/6765.html)：当前 B1 美式听力主线，只学习 Lesson 1～3 的工作场景；官方 YouTube、直接 MP3 和文本入口见[听力材料](../practice/listening/index.md)
- [VOA Let's Learn English Level 1](https://learningenglish.voanews.com/p/5644.html)：A2 美式口语转化，只使用 Lesson 8、41 和 47
- [925 English](https://www.businessenglishpod.com/category/925-english/)：A2 工作表达库；公开音频无需注册，完整 PDF 和练习需要会员，只有当前说话人是美式发音时才用于跟读
- [USA Learns 2nd English Course](https://www.usalearns.org/2nd-free-online-english-course) 和 [Access America](https://www.usalearns.org/Access-America)：需要免费注册并登录，只作可选补充
- British Council 和 BBC：当前只作少量多口音理解训练，达到 B2 后再提高比例

连续 5 段 B1 新材料达到以下标准后，保持 B1 工作材料为主，并每周加入一段美式 B2 试听：

1. 第一遍不看文本能理解约 70% 的主要信息。
2. 第二遍不看文本能理解约 80%。
3. 配套理解题正确率达到 80%。
4. 不看文本能用 3～5 句英语复述主题、关键事件和结果。

第一次听懂 50%～70% 的 B1 材料适合精听；低于 40% 时缩短片段或换一段更清楚的 B1 材料。连续 5 段美式 B2 新材料也达到上述标准后，再把英式或其他口音逐步提高到 30%，不一次性全部替换。

口语暂时不以复杂度升级，而检查下面四项：

1. 能用简单完整的句子连续表达 60～90 秒。
2. 能主动使用本轮选择的 3～5 个语言块。
3. 能回答两个相关追问。
4. 想不起复杂表达时会主动换成简单说法，而不是长时间沉默。

## 每四周固定测试

测试条件保持一致，才能纵向比较：

- 2 分钟自我介绍 + 3 分钟 stand-up + 5 分钟项目介绍
- 听一段没听过的 2 分钟材料两遍，然后脱稿复述
- 与 AI 或真人进行 10 分钟连续工作场景对话
- 用 10 分钟写一封进度汇报或 Bug 描述

重点观察：沉默卡顿是否减少、能否说完整句、是否依赖中译英，以及能否听懂并回答追问。四到八周没有变化时，调整材料难度或输出量。
