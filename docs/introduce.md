# Self Learning English

这是一个以真实输出为核心的个人英语训练仓库。

当前用途非常明确：为程序员寻找远程工作，以及进入国际团队后的真实工作交流
做准备。优先练习能立即用于会议、技术讨论和面试的听力与口语。

## 当前目标

- 听懂远程会议、技术讨论和面试中的主要信息
- 听完一段内容后，用英语复述大意
- 用简单完整的句子维持工作交流，听不清时能够主动确认
- 完成站会汇报、Bug 描述、技术讨论和需求确认
- 用英语介绍项目，描述代码、系统流程、技术方案和问题
- 适应跨时区协作、异步更新、远程面试和功能 Demo
- 主动使用听说训练中练过的表达，而不只是听得懂或看得懂

## 核心学习流程

```text
输入（听材料）
→ 第一次输出（复述）
→ 发现问题（语法、表达、词汇）
→ 提炼 3～5 个表达
→ 用自己的场景做替换练习
→ 再次输出（修正后的复述）
→ 把分析和目标写入练习记录
```

## 当前学习计划

采用两档计划：忙时完成最低版，时间充足时完成完整版。最低版是每天的底线，
完整版不是必须每天完成的硬指标。

当前不再使用墨墨背单词，也不安排其他独立的背词任务。单独背单词对现阶段的听说目标帮助有限，因此每天的时间都用于听力理解和口语输出。训练中遇到生词时，只按需查清意思和用法，并马上放回原句或复述中使用，不设每日新词数量。

### 当前材料

- B1 听力主线：[British Council B1 Listening](https://learnenglish.britishcouncil.org/free-resources/listening/b1)
  的工作场景和 BBC Office English
- A2 口语转化：[925 English](https://www.businessenglishpod.com/category/925-english/)
  和工作交流语言块
- 技术听力：VOA Technology Report 和有英文字幕的技术讲解
- 真实材料：Developer Tea、Stack Overflow Podcast 和 Soft Skills Engineering
- 输出：远程会议、站会、Bug、需求、技术解释、异步协作、项目介绍和面试

完整清单和手机收听方式见[听力材料](./practice/listening/index.md)。
《走遍美国》的历史练习记录继续保留，但不再作为当前精听主线。

### 最低版：每天 20～30 分钟

1. 听和理解 5～8 分钟：选择 1～3 分钟的材料，先盲听，再看文本确认。
2. 第一次脱稿复述 5 分钟：先完整说出来，不在卡点上长时间停留。
3. 检查和提炼 5～8 分钟：只选 3～5 个最影响表达的问题或句式。
4. 第二次复述 5 分钟：使用修正后的简单句，再完整说一遍。

如果当天只能做一件事，就完成一段 B1 工作听力，并把其中 3 个表达换成简单句，
用于自己的项目输出，不同时开启多份材料。

### 完整版：每天 60～90 分钟

- 核心输出 20～30 分钟：完成最低版
- 跟读 10～15 分钟：模仿当前材料的重音、停顿和连读
- 职场短听力 10～15 分钟：听完后用 3～5 句英语复述
- 技术短听力 10～15 分钟：截取带英文字幕或文本的 1～3 分钟片段
- 工作场景 15～20 分钟：把材料换成自己的项目，脱稿表达，检查后再说一遍
- 复听与再输出 5～10 分钟（可选）：重听最难的一段，或重说当天最卡的部分

### 每周工作场景

- 周一：听不清时确认 / 远程会议连接问题
- 周二：Stand-up / 异步进度汇报
- 周三：描述真实 Bug，包括预期、实际结果、复现步骤和原因猜测
- 周四：让 AI 扮演 PM，练需求确认和验收标准
- 周五：向同事解释代码、架构或数据流
- 周六：项目介绍 / 远程面试 / 功能 Demo
- 周日：复述本周最难的一段材料；状态不好时休息

### 材料安排

- 当前听力 B1：50% 分级职场英语、30% 清晰技术讲解、20% 真实材料
- B1 稳定后：40% 分级职场英语、30% 技术讲解、30% B2 或真实材料
- A2 材料主要用于跟读、替换和口语自动化

精听材料必须带文本或字幕，内容要能迁移到实际工作，连续语言要占主要部分。
影视和技术新闻只作补充；儿童主题、无意义声音或音效过多的内容直接淘汰。

### 听力和口语的级别标准

当前听力约为 B1，口语约为 A2。听力使用 B1 新材料训练；口语继续使用简单句，
重点解决卡顿、组织顺序和回答追问。

听懂率按主要信息估算，不按听出的单词数量计算：能否说出主题、人物目的、
关键事实和最后结果。

- [A2 Listening](https://learnenglish.britishcouncil.org/free-resources/listening/a2)：
  当前主线
- [B1 Listening](https://learnenglish.britishcouncil.org/free-resources/listening/b1)：
  电话、会议、采访以及清晰的日常或工作话题
- [B2 Listening](https://learnenglish.britishcouncil.org/free-resources/listening/b2)：
  更长的广播、访谈、演讲和包含复杂观点的熟悉话题

连续 5 段 B1 新材料都满足以下条件，再把 B2 或真实材料提高到训练量的 30%：

- 第一遍不看文本理解约 70%，第二遍达到约 80%
- 配套理解题正确率达到 80%
- 不看文本能用 3～5 句英语复述主题、关键事件和结果

第一次听懂 50%～70% 的 B1 材料适合精听；低于 40% 时缩短片段或换更清楚的
B1 材料。稳定达到 70% 以上时，每周加入一段 B2 试听。

口语暂时以能连续表达 60～90 秒、主动使用 3～5 个语言块并回答两个追问为目标，
不要求复述使用和听力材料一样复杂的句子。

### 每四周固定测试

- 2 分钟自我介绍 + 3 分钟 stand-up + 5 分钟项目介绍
- 听一段没听过的 2 分钟材料两遍，然后脱稿复述
- 与 AI 或真人进行 10 分钟连续工作场景对话
- 用 10 分钟写一封进度汇报或 Bug 描述

每次保持同题、同时长和同遍数。四到八周没有变化时，调整材料难度或输出量，
不单纯增加学习时长。

## 记录原则

- 不收集完整教材，只记录训练中真实遇到的问题
- 一次只训练 3～5 个表达
- 只记录真实犯过的错误
- 不单独背单词；生词和表达只在听力、复述和实际场景中学习
- 过时内容优先归档；删除知识类内容前先确认范围
- 语法随用随查，保留已有语法和发音资料
