# 归档内容

这个目录用于保留少量仍有历史价值、但当前不再维护的内容。

## 归档原则

可以放入归档的内容：

- 内容已经不适合当前主流程
- 仍然能反映过去学习过程
- 不会误导当前训练
- 没有明显错误或过时个人信息

不能放入归档的内容（应直接删除）：

- 旧面试材料
- 旧英文自我介绍
- 旧项目介绍
- 过时工作经历
- 可随时从网上获取的完整教材内容
